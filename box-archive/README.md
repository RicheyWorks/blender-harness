# box-archive (blender-team)

Files that existed only on the Grok Bot box (/workspace), rescued to GitHub on 2026-10-18 so nothing blender-team made lives only there.
- `renders/`: contact sheets and island renders (wave 3/4 sheets, eco lineups, tools catalog, contest island v5, Hephaestus landmark r2, UE island r3/view).
- `Blender-Boss-Asset-Tracker.xlsx`: asset tracker spreadsheet.
- `scripts/hq.py`: image brightness/histogram helper used for render checks.
Older box drafts of scripts that also exist on BLACKBEARD (bb_*.py, flagship.py, lodworker.py, ...) were not copied: the BLACKBEARD/GitHub versions are newer and authoritative.
`docs/blender-team-log.md` is the blender-team status log kept on the box.
